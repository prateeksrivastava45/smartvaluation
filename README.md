# SmartValuation
**Fundamental Stock Analysis · India**

A web-based multi-method equity valuation platform for NSE-listed Indian companies.

🔗 **Live Tool:** https://prateeksrivastava45.github.io/smartvaluation/

---

## What it does
Enter any NSE ticker (INFY, RELIANCE, TCS etc.) and instantly get:
- Multi-scenario DCF valuation (Bear / Base / Bull)
- WACC build-up using Damodaran sector betas
- FCFF with CapEx normalization
- Sensitivity analysis (WACC vs Terminal Growth Rate)
- P/E, EV/EBITDA and P/B relative valuation
- Composite intrinsic value with sector-appropriate weighting
- Warnings engine flagging data quality issues

## Tech Stack
- **Backend:** Python / Flask (deployed on Render)
- **Frontend:** HTML / CSS / JavaScript (deployed on GitHub Pages)
- **Data:** Screener.in (live scraping)
