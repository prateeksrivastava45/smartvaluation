# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SmartValuation, please report it responsibly. We appreciate your efforts to responsibly disclose security vulnerabilities.

### How to Report

1. **Do NOT** create a public GitHub issue for the vulnerability
2. **Do NOT** post about it in any public forum
3. Send a detailed report to: [Your Email/Security Contact]

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any proposed fixes (optional)

### Response Timeline

- We will acknowledge receipt within 24-48 hours
- We will provide an estimated timeline for a fix
- We will keep you updated on progress

### Safe Harbor

We commit to working with security researchers in good faith to resolve security vulnerabilities. We will:

- Not pursue legal action against security researchers who follow this policy
- Keep your details confidential if you request it
- Credit you in security advisories (if you wish)

## Security Best Practices

When using SmartValuation:

- Keep your Python and dependencies updated
- Never commit sensitive data (API keys, passwords)
- Use environment variables for configuration
- Review code before running untrusted scripts

---

Thank you for helping keep SmartValuation secure!
